## Why

当前发送评论给 Agent 时会构造包含任务标记、路径、上下文和处理指引的结构化 prompt，但用户希望评论派发更轻量：只把评论内容原样交给 Agent，并自动提交让 Agent 立即开始执行。

## What Changes

- 将单条评论、自动发送、历史单条发送和历史批量发送给 Agent 的内容调整为仅包含用户评论内容，不再附加任务说明、文档路径、被评论原文或上下文等额外信息。
- 在成功写入评论内容到终端后自动补充一次 Enter 键输入，使 Agent 无需用户手动回车即可开始处理。
- 保留现有保存语义、派发可用性校验、发送失败反馈和按钮防重复逻辑。

## Capabilities

### New Capabilities

- 无。

### Modified Capabilities

- `annotation-agent-dispatch`: 调整发送给 Agent 的 prompt 内容契约和终端提交行为。

## Impact

- 影响前端评论派发 prompt 构造逻辑与终端控制器写入行为。
- 影响评论抽屉显式发送、保存后自动发送、历史单条发送和历史批量发送。
- 不引入新的外部依赖，不改变本地评论保存数据结构。
